🚀 Step 0: Where do I type Python?

Python is a language you use to tell a computer what to do. You write instructions (called code), and the computer follows them from top to bottom.

  1. Open programiz.com/python-programming/online-compiler in your browser. It's free and needs no install.
  2. Delete the example code in the big box.
  3. Type (don't copy) a lesson's code, then press the Run button.
  4. Your answer shows in the box below. If you see red text, that's an error. Don't panic: it just tells you what to fix, and every coder gets them all the time.
💡 Python is strict about spelling, brackets ( ), quote marks " " and spaces at the start of lines. One missing quote can cause an error.

📖 Words to Know

  • Variable: a name that holds a value, like age = 13.
  • String: text inside quotes, like "hello".
  • Integer: a whole number like 7. A float has a decimal point, like 7.5.
  • Tuple: a fixed group of items in ( ).
  • Element or item: one thing inside the tuple.
  • Index: the position number of an item, starting at 0.
  • Immutable: cannot be changed after it's made.
  • Unpacking: pouring a tuple's items into separate variables.
  • Loop: code that repeats. Function: a named block of code you can reuse.
