Lists: your very own magic basket 🧺

A slow, friendly guide to Python lists — one idea at a time, no rushing.

Hi Eniola! 👋 Today we're learning about lists — one of the most useful tools in coding. A list is just a way to keep a bunch of things together in one place, kind of like a basket. Let's go step by step.

1 What even is a list?

Imagine a basket where you keep your favorite fruits. In Python, we write that basket like this:

fruits = ["mango", "banana", "orange"]

The square brackets [ ] are the basket. The words inside, separated by commas, are the things in the basket. That's it — you just made a list!

mango
banana
orange
A list can hold words, numbers, or even other lists — anything you like.

2 Finding things by their spot (index)

Every item in a list has a numbered spot, called an index. Here's the trick: Python starts counting from 0, not 1.

0mango
1banana
2orange
print(fruits[0])  # mango
print(fruits[1])  # banana
print(fruits[2])  # orange

So fruits[0] means "give me whatever is in spot 0" — which is mango.

Try it in your head 🧠

What do you think fruits[2] prints?

Reveal the answer
It prints orange, because orange sits at spot 2 (remember, we start counting from 0!).

3 Adding new items

Want to add a new fruit to your basket? Use .append() — it means "add this to the end."

fruits.append("pineapple")
print(fruits)
# ['mango', 'banana', 'orange', 'pineapple']
mango
banana
orange
pineapple
Think of .append() as gently placing something on top of the basket.

4 Removing items

Changed your mind about banana? Use .remove() to take it out.

fruits.remove("banana")
print(fruits)
# ['mango', 'orange', 'pineapple']

Python looks through the basket, finds "banana", and lifts it out. Everything else stays exactly where it was.

Quick check ✏️

After removing banana, what is fruits[1] now?

Reveal the answer
It's orange — because once banana leaves, everything shifts up one spot, so orange moves from spot 2 into spot 1.

5 Looking at every item (looping)

What if you want to say hello to every fruit, one by one? That's what a for loop is for.

for fruit in fruits:
    print("I love", fruit)

This reads almost like English: "for each fruit in the list, print a message about it." Python will run the print line once for every single item.

The loop automatically stops when it reaches the end of the list — no counting needed!

6 How many things are in the basket?

Use len() — short for "length" — to count the items.

print(len(fruits))  # 3

Last challenge 🌟

If you .append("grape") to a list that had 3 items, what does len() return now?

Reveal the answer
It returns 4 — appending adds one more item, so the length grows by 1.

7 Now it's your turn: 5 projects

Reading is great, but typing your own code is how it really sticks. Try these in order — each one uses what you just learned.

1. Snack Shelf 🍪

Make a list called snacks with 4 of your favorite snacks. Print the whole list, then print just the snack at index 2.

2. Playlist Builder 🎵

Make a list called songs with 3 songs. Use .append() to add 2 more songs. Print the final list — it should have 5 songs.

3. Chore Checker ✅

Make a list called chores with 5 chores. Once you finish one (pick any!), use .remove() to take it off the list. Print the list before and after.

4. Friend Greeter 👋

Make a list called friends with the names of 4 friends. Use a for loop to print "Hi, [name]!" for each one.

5. Basket Counter 🧮

Make a list called basket with any 6 items. Use len() to print how many items are inside. Then .append() one more item and use len() again — check the number went up by 1.

You just learned 🎉

  • [ ] makes a list — your basket of items
  • Each item has an index, starting from 0
  • .append() adds an item to the end
  • .remove() takes an item out
  • for item in list: visits every item, one by one
  • len() tells you how many items are inside
